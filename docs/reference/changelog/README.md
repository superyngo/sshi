# Changelog archives

The root [`CHANGELOG.md`](../../../CHANGELOG.md) carries **`[Unreleased]` plus the current version
series only**. Completed series are moved here verbatim — same format, same ordering, no edits.

| Archive | Covers |
|---|---|
| [`v0.x.md`](v0.x.md) | v0.1.0 (2026-03-06) … v0.9.0 (2026-05-06) |

**When to archive.** On the first release of a new major series (v2.0.0), move the whole
preceding series into `v1.x.md` here and add a row above. Never archive the series the next tag
belongs to: release notes and version checks read the **root** `CHANGELOG.md`.
